# RESULTS_SPEC.md — Results-capture contract

Purpose: every number, percentage, table and figure in the paper must be traceable to saved
files produced by code. This spec defines exactly what each run saves and how results are
aggregated into paper-ready outputs. Implement it first (Phase 1) as `src/results/` and use it
for every experiment, including baselines.

---------------------------------------------------------------------------------------------

## 1. Directory layout

```
results/
  runs/
    <run_id>/                      # one folder per run (never overwritten)
      config.yaml                  # fully-resolved config (after defaults + CLI overrides)
      env.json                     # reproducibility info (see §3)
      status.json                  # {"status": "running|completed|failed", "error": "...", "started": ..., "ended": ...}
      fold_<k>_seed_<s>/
        train_log.csv              # epoch, step, train_loss, val_loss, val_macro_f1, val_acc, lr, seconds
        val_logits.npy             # [n_val, n_classes]   (for calibration)
        val_meta.csv               # clip_id, group, label_idx
        test_logits.npy            # [n_test, n_classes]  (written once, after model is final)
        predictions.csv            # see §4
        metrics.json               # see §5 (per fold/seed)
        calibration.json           # temperature T, ECE before/after, chosen thresholds (see §6)
      summary.json                 # aggregated over folds × seeds (see §7)
  registry.jsonl                   # one line per run, appended (see §8)
  dataset_stats.json               # paper Table 1 / Section 3 (see §9)
  significance/
    <run_a>__vs__<run_b>.json      # paired bootstrap results (see §10)
  figures/                         # PNG (300 dpi) + PDF of every paper figure
  tables/                          # each paper table as .md and .csv (and .tex)
  paper_numbers.json               # flat key -> value map used to fill the paper (see §11)
  RESULTS.md                       # human-readable report, regenerated by src/report.py
```

`run_id` format: `<experiment_id>__<short_name>__<YYYYMMDD-HHMMSS>__<git7>`
e.g. `E10__ast_ft__20261120-141502__a1b2c3d`.

## 4. predictions.csv (one row per test clip)

| column | meaning |
|---|---|
| clip_id | stable ID from metadata.csv |
| group | baby/recording/device group ID |
| dataset | source dataset |
| fold, seed | ints |
| y_true | label string |
| y_pred | argmax label string (uncalibrated) |
| p_<class> | calibrated probability per class (after temperature scaling; raw if not calibrated yet) |
| confidence | max calibrated probability |
| abstain@0.9cov, abstain@0.7cov, abstain@0.5cov | bool, using thresholds chosen on validation |

## 5. metrics.json (per fold × seed)

```json
{
  "n_test": 0, "n_classes": 0, "labels": [],
  "accuracy": 0.0, "macro_f1": 0.0, "weighted_f1": 0.0, "balanced_accuracy": 0.0,
  "per_class": {"hungry": {"precision": 0.0, "recall": 0.0, "f1": 0.0, "support": 0}},
  "confusion_matrix": [[0]],
  "nll": 0.0, "brier": 0.0,
  "ece_15_uncal": 0.0, "ece_15_cal": 0.0,
  "aurc": 0.0,
  "precision_at_coverage": {"1.0": 0.0, "0.9": 0.0, "0.7": 0.0, "0.5": 0.0},
  "macro_f1_at_coverage":  {"1.0": 0.0, "0.9": 0.0, "0.7": 0.0, "0.5": 0.0},
  "realised_coverage":     {"0.9": 0.0, "0.7": 0.0, "0.5": 0.0},
  "top2_accuracy": 0.0,
  "train_seconds": 0, "params_total": 0, "params_trainable": 0,
  "inference_ms_per_clip_cpu": 0.0
}
```
Detection runs (task=detection) instead record: accuracy, f1, precision, recall, roc_auc,
false_alarms_per_hour (on the long held-out household recording), miss_rate.

All metrics computed by ONE shared module `src/results/metrics.py` (unit-tested). Definitions:
- **macro_f1**: sklearn `f1_score(average="macro", zero_division=0)` over labels present in the label set.
- **balanced_accuracy**: sklearn `balanced_accuracy_score`.
- **ECE**: 15 equal-width confidence bins, |acc − conf| weighted by bin fraction.
- **NLL**: mean cross-entropy of calibrated probs. **Brier**: mean squared error vs one-hot.
- **Risk–coverage**: sort by confidence desc; coverage c = fraction kept; selective risk = 1 − accuracy on kept.
  **AURC** = area under risk–coverage curve (trapezoid over all n points).
- **precision_at_coverage[c]**: accuracy on the test clips whose confidence ≥ τ_c, where τ_c is the
  threshold that gives coverage c **on the validation set** (so realised test coverage may differ —
  record it in realised_coverage).
- **macro_f1_at_coverage[c]** (added 2026-11-18, approved by Idris, BEFORE the final model E36 was run):
  macro-F1 on the same kept test clips (confidence ≥ τ_c from validation), averaged over ALL classes of the
  label set with zero_division=0 — a class with no kept clips and no kept predictions scores 0, so abstaining
  on a whole minority class lowers the score. "1.0" equals macro_f1. Runs created before this date get it
  recomputed by report.py from their saved predictions.csv (abstain@ columns), with no retraining.
- **inference_ms_per_clip_cpu**: median over 50 clips, batch 1, CPU, after 5 warm-up calls.

## 6. calibration.json

```json
{"temperature": 1.0, "fit_on": "val", "ece_val_before": 0.0, "ece_val_after": 0.0,
 "thresholds": {"0.9": 0.0, "0.7": 0.0, "0.5": 0.0}}
```

## 7. summary.json (aggregated)

For every scalar metric: `{"mean": x, "std": y, "n": folds*seeds, "values": [...]}` aggregated
over all fold × seed combinations. Also include `"pooled"` metrics computed on the concatenation
of all out-of-fold predictions for seed 0 (used for confusion matrix figure and significance tests),
plus `per_class_recall_mean_std`.

## 8. registry.jsonl (append-only)

One JSON object per line:
```json
{"run_id": "...", "experiment_id": "E10", "name": "ast_ft", "status": "completed",
 "parent_run": "...", "change_vs_parent": "...", "paper_table": "T3", "paper_row": "AST, fine-tuned",
 "task": "reason", "folds_file_sha256": "...", "git_commit": "...",
 "macro_f1_mean": 0.0, "macro_f1_std": 0.0, "accuracy_mean": 0.0, "accuracy_std": 0.0,
 "ece_cal_mean": 0.0, "created_utc": "...", "superseded_by": null, "notes": ""}
```
If a run is replaced by a better-configured one for the same paper row, set `superseded_by`
in a NEW line (append a correction record) — never edit old lines. report.py uses the latest
non-superseded completed run per (paper_table, paper_row).

## 9. dataset_stats.json (from src/dataset_stats.py)

Per dataset and overall: n_clips, n_groups, total_minutes, duration mean/std/min/max,
class counts, class percentages, clips per group (min/median/max), n_duplicates_removed,
per-fold class counts (the crosstab), and the label-mapping table actually applied.

## 10. Significance (src/significance.py)

Paired bootstrap over test clips (pooled out-of-fold predictions, seed 0), 10,000 resamples,
resampling **groups** (babies) not clips, statistic = macro-F1 difference. Save
`{"run_a", "run_b", "delta_macro_f1", "ci95": [lo, hi], "p_value", "n_resamples", "resample_unit": "group"}`.
Also McNemar's test on accuracy as a secondary check.

## 11. paper_numbers.json — the bridge to the paper

Flat key → value map (values already formatted as strings for the paper, plus raw floats under
`_raw`). report.py must generate at least these keys (extend as needed):

| Key | Fills paper placeholder |
|---|---|
| model_name | [MODEL NAME] everywhere |
| abstract.detection_acc | Abstract “cry-detection accuracy of [XX.X]%” |
| abstract.reason_macro_f1_ours | Abstract “macro-F1 of [0.XX]” |
| abstract.reason_macro_f1_deepinfant | Abstract “versus [0.XX]” |
| abstract.selective_precision / abstract.selective_coverage | “[XX.X]% precision at [XX]% coverage” |
| abstract.ece_ours | “ECE of [0.0XX]” |
| datasets.* | Table 1 counts, Section 3 class distribution |
| dapt.hours_unlabelled | Section 4.3 “[N hours]” |
| T3.<row_slug>.{accuracy,macro_f1,balanced_acc,ece} | Table 3 cells as "mean ± std" |
| T4.<row_slug>.{macro_f1,delta} | Table 4 ablation |
| T5.{cov100,cov90,cov70,cov50}.{precision,macro_f1,threshold} | Table 5 |
| T5b.<row_slug>.{ece_before,ece_after,aurc,prec90,prec70,prec50,mf1_90,mf1_70,mf1_50} | Table 5b (every T3 model) |
| T6.* | Detection results (Section 6.4) |
| T2.* | Implementation details table (hardware, versions, hyperparameters actually used) |
| eff.<row_slug>.{params_m,trainable_m,size_mb,cpu_ms,cpu_ms_1t}, eff.hardware | Efficiency (Phase 9, `src/efficiency.py` → results/efficiency.json): one machine for all models; median ms per input, batch 1, raw waveform → logits incl. features, 5 warm-ups, 50 fold-0 test clips (reason: 7 s clip; detectors: 1 s frame); size = serialized fp32 state_dict. Per-run `inference_ms_per_clip_cpu` is hardware-dependent and not compared across rows. (added 2026-11-20) |
| sig.ours_vs_deepinfant.{delta,ci95,p} | Significance sentence in 6.1 |
| leak.random_split_macro_f1 / leak.grouped_split_macro_f1 | Last row of Table 4 + discussion |

Formatting rules: percentages 1 decimal ("87.3 ± 2.1"); F1/ECE 3 decimals ("0.712 ± 0.034");
p-values 3 decimals or "< 0.001". Each key also stores `source_run_id` under `_sources`.

## 12. RESULTS.md (regenerated, never hand-edited)

Sections: run index (from registry), Tables T1–T6 in markdown, figure list with paths,
significance results, warnings (runs with mismatched folds hashes, missing seeds, superseded runs,
any paper placeholder still unfilled).
